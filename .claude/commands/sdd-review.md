description: SDD шаг 5 — независимая сверка реализации со спекой (свежий контекст)
argument-hint: [specs/NNN-slug]
---
Аргументы: $ARGUMENTS

1. Определи папку фичи (аргумент или последняя в specs/).
2. Передай субагенту `spec-reviewer` только путь к папке фичи. Не пересказывай ему,
   как и почему ты реализовывал — ревьюер должен смотреть без этого контекста.
3. Покажи пользователю отчёт ревьюера как есть.
4. Для каждого замечания предложи действие: исправить код / обновить спеку (с согласия пользователя) / не проблема.
   Ничего не исправляй, пока пользователь не выберет.
